WORMWISE FIELD OUTLINE WORKFLOW
===============================

CURRENT PROJECT DECISION
------------------------
A field can be registered with its name and reported area before an outline is
available. A new assessment cannot proceed to setup or Station 1 until that
field has a confirmed approximate outline.

If the outline is missing, show:

    Complete field outline

Preserve any saved assessment draft. Do not delete it because the field still
needs an outline.

The outline is used for scouting orientation, route layout, and area
comparison. It is not a legal, cadastral, property, or survey-grade boundary.

WORKFLOW
--------
1. Register the field and crop-cycle information.
2. Optionally record an averaged entrance GPS point. This point is a practical
   reference and is not a boundary.
3. Open the outline editor.
4. Add at least three valid points using visual placement, averaged phone-GNSS
   corners, or a mixture of both.
5. Review the polygon, calculated area, and perimeter.
6. Confirm the approximate-outline statement and save a new boundary version.
7. Return to Scan, where assessment setup can now proceed.

SAFETY AND DATA RULES
---------------------
- Do not require a user to walk an unsafe or recently treated field edge.
- Store phone-reported accuracy with GPS-derived observations.
- Never invent GPS accuracy for visually placed points.
- Never turn an entrance point into a polygon.
- Never silently replace reported area with calculated polygon area.
- Preserve prior boundary versions and linked assessment records.
- Missing online map tiles must not block the local outline and assessment
  workflow.

CURRENT MAP FOUNDATION
----------------------
The field overview and outline editor currently use Esri World Imagery as an
online reference and provide an OpenStreetMap alternative. That direct online
imagery integration still needs production review for terms, attribution,
authentication, and expected usage.

Scan uses the same Esri World Imagery online background as the Map tab and has
a deterministic illustrated-field fallback. Licensed local imagery packages
may be added under the rules in:

    docs/SCAN_IMAGERY_DEPLOYMENT.md

The maintained detailed specification is:

    docs/FIELD_LOCATION_AND_OPTIONAL_BOUNDARY.md
